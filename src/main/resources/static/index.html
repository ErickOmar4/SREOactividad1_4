Panel de la API

primer proyecto desde Spring Initializr

¿Cómo funciona? Cada tarjeta es un endpoint. Ver resultado abre una página con la respuesta en tabla; Ver API abre la dirección real (JSON sin formato) en una pestaña nueva. La ruta que se va a consultar aparece arriba de cada formulario y se actualiza mientras escribes.

Proyecto

Nombre del proyecto

Devuelve el nombre del proyecto. Sirve para identificar de quién es la instancia que está corriendo.

GET/api/proyecto/nombre

Estado del servidor

Objeto JSON con el estado, el autor, la versión de Java, el puerto y la fecha del servidor.

GET/api/proyecto/estado

Materias

Todas las materias

Lista completa de materias (datos simulados).

GET/api/materias

Buscar por ID

Devuelve una sola materia. Si el ID no existe, la API responde 404.

GET/api/materias/{id}

Buscar con filtros

Todos los campos son opcionales y se pueden combinar. El nombre no distingue mayúsculas ni acentos (programacion encuentra Programación).

GET/api/materias
